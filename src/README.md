
# Source Code

This folder is reserved for reusable Python modules for ShopInsight AI.

## Milestone 1

The current implementation is available in:

`notebooks/ShopInsight_Milestone1.ipynb`

The notebook includes:
- Dataset loading and preprocessing
- Logistic Regression, Decision Tree, and KNN models
- Model evaluation and visualizations
- PageValues feature ablation
- Class imbalance experiments
- Decision threshold tuning
- Purchase predictions and probability visualization

## Milestone 2

We plan to organize reusable code into Python modules and implement:
- A neural network from scratch using NumPy
- Forward propagation and backpropagation
- Stochastic gradient descent (SGD)
- Additional model comparisons and evaluation

The source code will be moved into this folder as reusable components are developed.
