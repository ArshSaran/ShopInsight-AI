
## Dataset

**Name:** Online Shoppers Purchasing Intention Dataset  
**Source:** UCI Machine Learning Repository  
**Dataset ID:** 468  
**Dataset Link:** https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

**Original Sessions:** 12,330  
**Sessions After Removing Duplicates:** 12,205 
**Target Variable:** Revenue

- True: Purchase
- False: No Purchase

The dataset is downloaded programmatically in Google Colab, so the original CSV file is not stored in this repository.
