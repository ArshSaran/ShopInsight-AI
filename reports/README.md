# Project Reports

This folder contains the project reports and documentation for **ShopInsight AI**, developed for CMPT 310 – Artificial Intelligence, Group 13.

## Current Milestone: Milestone 1

**Milestone 1 – Progress and Baseline Implementation**

For Milestone 1, we have completed:

- Dataset exploration and cleaning
- Data preprocessing and train/validation/test splitting
- Logistic Regression, Decision Tree, and KNN baseline models
- Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC
- Confusion matrices and performance visualizations
- Experiments with PageValues, class imbalance, and decision thresholds
- Sample purchase predictions and probability estimates

The implementation and experiment outputs are available in the `notebooks/` and `results/` folders.
